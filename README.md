# Roll-a-ball (Unity Project)

## Overview
A Unity-based maze game inspired by Pac-Man mechanics. The player controls a ball while avoiding an AI enemy using NavMesh.

## Features
- NavMesh Agent enemy with patrol behavior
- Line-of-sight detection (~7–10 units)
- Procedurally generated maze with random escape paths
- Player movement with physics

## Tech Stack
- Unity
- C#

## How to Run
1. Open the project in Unity Hub
2. Use Unity version 6
3. Press Play in the editor
